Trader Business Control — Client PWA

This package is the working Client V6 with PWA installation support added.

IMPORTANT:
- Host the files on HTTPS (a real domain, Netlify, Vercel, GitHub Pages, etc.).
- Open client.html from that HTTPS site on the phone.
- Android Chrome: use the browser menu and choose Install app / Add to Home screen.
- iPhone Safari: Share -> Add to Home Screen.
- The app remains read-only and continues fetching live business data from Supabase.
- The client must complete its one-time Supabase connection if not already configured.
